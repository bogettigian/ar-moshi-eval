# AR Moshi Eval

Evaluation framework for the ar-moshi project. Runs any Moshi-compatible
checkpoint (Moshi base, future LoRA / fine-tune variants) over a fixed bank
of Spanish prompts and aggregates per-block / per-prompt annotations.

## Layout

```
prompts/bank.yaml        # source of truth: 21 prompts (Blocks A–D), stable IDs
prompts/wav/             # generated by synth_prompts.py (XTTS v2, 24 kHz mono)
runs_config/             # per-run config templates (zero_shot, post_lora)
runs/<id>/               # one run = one (checkpoint × backend × temperatures × seed)
  config.yaml            # run parameters
  outputs/<prompt_id>/   # response.wav, text_tokens.txt, output.json
  auto_metrics.csv       # ASR transcript + Spanish-LM perplexity
  annotations.csv        # human Likert 1-5 on naturalness + meaningfulness,
                         # filled in by hand after listening
reports/                 # comparison CSVs produced by score_runs.py
live_sessions/           # interactive full-duplex sessions (Block E, TODO)
src/
  synth_prompts.py       # generate prompt wavs with XTTS v2
  run_eval.py            # run a model over the bank
  auto_annotate.py       # ASR + perplexity per response
  score_runs.py          # aggregate metrics across runs
  models/
    base.py              # ModelRunner protocol + PromptOutput dataclass
    factory.py           # load_model(cfg) — dispatch by model_type
    moshi_pytorch.py     # the only runner (PyTorch, mps/cuda/cpu)
log.ini                  # logging config (console + rotating file in logs/)
logs/                    # rotating log files (gitignored)
docs/                    # project state + research notes (gitignored, local only)
  NEXT_STEP.md           # current state and ordered backlog — read this first
  INTEGRATION.md         # contract with the sibling fine-tuning repo
  research/              # paper notes and derived research documents
  papers/                # source PDFs
```

## Evaluation metrics

- **Automatic** (`auto_metrics.csv`, written by `src.auto_annotate`):
  - `transcript_asr` from Whisper large-v3.
  - `ppl` of a Spanish causal LM (default `BSC-LT/salamandra-2b`) over the
    ASR transcript. High PPL = low Spanish fluency in the response.
- **Human** (`annotations.csv`):
  - `naturalness` (1–5 Likert): how natural the dialogue sounds.
  - `meaningfulness` (1–5 Likert): how well the speech can be understood.

## Bank

21 prompts in Spanish across four blocks:
- **A** — basic comprehension (factual single-turn).
- **B** — instruction following (literal repetition, sequence execution, constraints).
- **C** — multi-turn (two sessions of three turns each sharing KV cache).
- **D** — open conversational Spanish.

IDs are stable — never rename them; they index `annotations.csv` and `runs/<id>/outputs/`.

## Setup

```bash
uv pip compile --generate-hashes --universal pyproject.toml -o requirements.txt
uv pip sync requirements.txt
```

Logging is configured by `log.ini`: console + a daily-rotated file in
`logs/final.log`. Every entry point creates `logs/` and loads the config on
start.

## Flow

1. **Synthesize the prompts to wav** (idempotent; use `--force` to regenerate):

   ```bash
   python -m src.synth_prompts
   ```

2. **Run a model over the bank.** Only the PyTorch backend is supported
   (`device: mps` on Mac, `cuda` on a GPU box):

   ```bash
   python -m src.run_eval --config runs_config/zero_shot_t08.yaml
   ```

   Use `--dry-run` to create the run dir + empty `annotations.csv` without
   loading the model.

3. **Auto-annotate** (ASR + Spanish-LM perplexity):

   ```bash
   python -m src.auto_annotate --run-dir runs/<id>/
   ```

   Idempotent; pass `--force` to recompute. Override models with
   `--asr-model` / `--lm-model` (defaults: Whisper large-v3, Salamandra-2b).

4. **Annotate by hand** the subjective columns in `runs/<id>/annotations.csv`
   (`naturalness`, `meaningfulness`) while listening to the wavs.

5. **Compare runs** (e.g. zero-shot vs LoRA vs fine-tune):

   ```bash
   python -m src.score_runs \
     runs/<zeroshot_run> \
     runs/<lora_run>
   ```

## Per-run `config.yaml`

```yaml
model_type: moshi_pytorch
tag: zeroshot_t08
checkpoint: kyutai/moshiko-pytorch-bf16   # HF repo id or local dir with config.json
lora_weight: null              # optional; path to lora.safetensors
temperature_audio: 0.8
temperature_text: 0.7
top_k_audio: 250
top_k_text: 25
cfg_coef: 1.0
seed: 0
device: cuda                    # mps | cuda | cpu
```

See `runs_config/` for the zero-shot config and `post_lora_template.yaml`
for fine-tune evaluations.
